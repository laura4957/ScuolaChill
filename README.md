# ScuolaChill

Gestionale scolastico per direttore, docenti e studenti: classi, materiale didattico, verifiche e voti.

Progetto del corso full stack. Prima del codice viene il PRD, che si trova in [`docs/PRD.md`](docs/PRD.md).

## Stato dei documenti

| Documento | Stato |
| --- | --- |
| PRD · Prima parte (il cosa) | Bozza, in revisione |
| PRD · Seconda parte (il come) | Da scrivere |
| PRD · Terza parte (tempi e valutazione) | Da scrivere |

## Struttura della repository

```text
scuolachill/
├─ docs/
│  └─ PRD.md
├─ .gitignore
└─ README.md
```

Il codice arriverà dopo la validazione del PRD.
